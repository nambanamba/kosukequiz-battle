## ★前回（328af80）の失敗を繰り返さないための方針
前回は「答えの語の**包含一致**」で機械的に埋めたため、
`沖縄 → 近郊農業` / `「40」 → 「60」` / `沖合漁業 → 遠洋漁業` のような
**意味的に別物への紐づけが大量に発生**した（完全一致は329件中95件だけ）。
**配信後は一度きり実行なので、いまも直せない。**

今回は次の3つを守っている。
1. **答えの完全一致のみ。包含一致は使わない**
2. **1対多は採らない**（同じ語で複数当たるものは別物が混ざるため見送り）
3. **対応がつかないものは、無理に紐づけず記録を捨てる**

### 答えの比べ方（ここが今回の肝）
括弧の中だけでは足りない。実データにこういうものがある。

```
旧 t5-9    大阪府に広がり，近郊農業がさかんな（⑨大阪）平野です。
新 kaki5_12 （大阪）平野です。   ← これが正しい相手
新 kaki5_13 （大阪）湾です。     ← 括弧の中だけ見ると「大阪」で一致してしまう
```

さらに、括弧の切れ目が旧と新でずれることがある。

```
旧 t8t-14  …日本一長い山脈は（奥羽山脈）です。   ← 括弧の中に「山脈」がある
新 kaki8_21 （奥羽）山脈です。                    ← 括弧の外に「山脈」がある
```

→ **括弧の中と直後の語をつないで1つの語にしてから、完全一致で比べている。**
　（「奥羽」＋「山脈」＝「奥羽山脈」でそろう。「大阪平野」と「大阪湾」は別物のまま）
→ 旧問題の「（地図で位置を確認）」のような注記は、答えではないので落としている。
