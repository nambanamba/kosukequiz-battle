# kosukequiz-battle

中学受験（四谷大塚「予習シリーズ」5年下）の一問一答クイズアプリです。1対1のリアルタイム早押し対戦（社会・理科の暗記系）と、一人で解く自習モード、理科の「今日の計算問題」（範囲・問題数指定＋印刷）を備えます。GitHub Pagesでホストする静的サイトで、対戦相手同士の通信は [Trystero](https://trystero.dev/)（サーバーレスWebRTC）でブラウザ間を直接つなぎます。バックエンドサーバーやアカウント登録は不要です。

旧姉妹アプリ「kosukequiz」（社会のみ・対戦機能なし）は2026-08-29に廃止し、本アプリに一本化しました。以降、社会・理科とも問題データはこのリポジトリの `data.js` が唯一のソースです。

## 遊び方

1. ホーム画面で科目（社会／理科）を選ぶ
2. 暗記系の問題：一方が「部屋をつくる」で出題する単元・問題数を選び、発行された4桁のコードをもう一方に伝える → もう一方が「部屋に入る」で参加 → 早押しボタンで解答権を取り合い、答え合わせは口頭で行い、押さなかった側が〇✕を判定する（一人で解く「一人で始める」モードもあり）
3. 理科の計算問題：「今日の計算問題」で回の範囲と問題数を指定して出題（対戦・ソロの対象外。印刷して紙で解ける）

## data.js の更新方法

このリポジトリの `data.js`／`images/` が社会・理科ともに唯一のソースです。他アプリからのコピーは発生しません。新しい問題データは `5年下\quiz_csv\` で作成したJSONを、このリポジトリのdata.js取り込み担当セッションが直接反映します。

### data.js のスキーマ

```js
{ id, subj, u, q, a, img?, kai?, kind?, sol?, note? }
```

- `subj`：`"社会"` | `"理科"`（必須）
- `kind`：`"memo"`（暗記・省略時のデフォルト）| `"calc"`（計算問題。対戦・ソロには出題されず、「今日の計算問題」モードのみ）。社会には付与しない。
- `kai`：回番号（理科のみ、「今日の計算問題」の範囲指定に使用）
- `sol`：計算問題の解説（理科のcalcのみ。印刷の解答用紙で使用）
- `note`：出典（例：`本文、7P`）。存在すればクイズ画面に「出典：〇〇」と小さく表示される（2026-08-29〜）。省略可（未設定の項目は表示なし）。旧データの大半（元のJSONが失われている社会・旧kosukequiz時代の項目）は未設定のまま。
- id接頭辞：社会は `t`/`z`/`s`・`simg`/`g`、理科は `r{回}m{連番}`（暗記）／`r{回}c{連番}`（計算）。衝突厳禁（`stats`/`edits` はidキーで永続化されるため）。

## 通信のしくみ

- `index.html` 内で `https://esm.run/trystero` から Trystero をESM importして使用（ビルド不要）
- 部屋作成時に発行される4桁の数字コードが、そのままTrystero上の部屋IDになる。コードとアプリ固有のappIdの組み合わせで部屋が識別されるため、通常の利用では他の利用者と部屋がぶつかることはない
- 早押しの勝敗判定は「部屋をつくった側（ホスト）」が一元的に決定し、両者に結果を通知することで、双方の端末の時計のずれに影響されず一意に決まるようにしている
- 通信キャリアの回線状況によっては、まれにP2P接続が確立できない場合がある。問題が頻発する場合はFirebaseなど別のシグナリング手段への切り替えを検討する
