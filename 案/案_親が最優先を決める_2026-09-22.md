# 案：親が「★最優先」の問題を決められるようにする（2026-09-22・対戦アプリ担当）

## 1. いまの作り（実物で確かめたこと）

| 見たもの | いまの形 |
|---|---|
| 記録 | `kq_battle_stats_v1`（localStorage）。`stats[id] = {correct, wrong, box, nextDue, lastCorrectAt, lastAnswered}` |
| ほかの保存 | 設定・直した問題・前回まちがえた問題・途中再開 などが**すべて別のキー**で localStorage |
| 問題一覧 | 行は `data-qid` 付きで1問1行。単元の選択・「未クリア／よく間違える／未実施のみ」・優先度・難易度・日付で絞れる。**並べ替えは無い（data.js の順）**。図も行に出る |
| CSV 書き出し | 列: `ID, 単元, 問題, こたえ, 正解した回数, まちがえた回数, 状態, 最終正答日, 最終回答日, 連続正解数` |
| CSV 読み込み | ★**列名で読む。知らない列は無視する**（2026-09-13 に「連続正解数」を足したときも、古いファイルで動いている） |
| 出題の並び | ★**「3段の並び」が効くのは「よく間違える／未クリア」を ON にしたときだけ**。ふだん（どちらも OFF）は**シャッフル**か**出題順どおり** |
| 一人・二人 | どちらも同じ `buildFinalPool()` で問題を決めている |

★**大事な発見**: 「★を0段目にして3段より先に」だけだと、**ふだん（トグル OFF）の出題では★が先に来ません。**
→ ★は**どのモードでも先頭に置く**作りにします（シャッフルでも、出題順どおりでも、3段でも）。
　 そのあとで「問題数（10問・20問…）」で切るので、**★は必ず入ります**。

## 2. ★どの端末に保存されるか

**★は、付けた端末にだけ残ります**（記録と同じ localStorage）。**親のスマホで付けても、お子さんの端末には届きません。**

→ 案（どれか。組み合わせ可）
- **A. お子さんの端末で、親が付ける**（いちばん簡単。何も運ばなくてよい）
- **B. CSV で運ぶ**: 書き出しに「**最優先**」の列を1つ足す（★なら「★」）。読み込みで★を**足す**
  - ★**古い版とも壊れない**: 古い版は知らない列を無視する／新しい版は列が無ければ★に触らない（実物の読み込みの作りで確認）
  - 読み込みは**足すだけ（外さない）**にする。外すのはその端末で（取り込むたびに消えると事故になるため）

## 3. ★記録を壊さない
- ★は**記録（`stats`）とは別の箱**に持つ: `kq_battle_priority_v1`（id の一覧）。**漢字プリントの `kanji_app_picked_v1` と同じ形**
- **記録には1文字も触らない**。古い版で開いても、知らない箱は読まれないだけ
- 問題データ（`data.js`）には持たせない（端末ごとに親が決めるものなので）
- 問題が消えた id の★は、黙って無視する（出題にも数にも入れない）

## 4. ★はいつ外れるか（ユーザーが選ぶ）

| 案 | 動き | よいところ | 気になるところ |
|---|---|---|---|
| **① 親が外すまで残る** | 親が一覧で外す | 漢字プリントと同じ。わかりやすい | 覚えたあとも先に出続ける |
| **② 2連続正解で自動で外れる** | 連続正解が2になったら外れる（いまの「2段目を抜ける」と同じ線） | 放っておいても片づく | 親が「まだ残したい」ときに困る |
| ③ ①＋一覧に「★で2連続正解ずみ」と印 | 外れないが、覚えたものが一覧で分かる | 親が判断できる | 少しだけ画面が増える |

私は **① か ③** を推します（「親が決める」という依頼の言葉に合う）。

## 5. ★が0件のとき
**いまとまったく同じ動き**にします（★の箱が空なら、並びも問題数も1問も変わらない）。検査で確かめます。

## 6. 画面の案（短く）

### 案1：一覧で付けて、出題では★が先に出る（たたき台そのまま・いちばん小さい）
- 問題一覧の各行の右上に **☆** ボタン。押すと **★**（もう一度で外れる）
- 一覧の上に「**★だけ表示**」の絞り込みと、「**いま表示中を全部★／全部外す**」（回・単元で絞ってからまとめて付けられる）
- ホームの問題数の表示に「**（★最優先 N問が先に出ます）**」と1行
- 出題では、**選んだ単元の中の★**を先頭に、残りはいまどおり
- ★どうし の順は3段の並び（まだ正解していない→…）でそろえる

### 案2：案1 ＋ ホームに「★最優先だけやる」ボタン
- 案1に加えて、ホームに **「★最優先だけやる（N問）」** のボタン1つ
- **単元の選択に関係なく、★の問題だけ**を出す（1タップ）
- 「全部はできないので」（09-21）の言葉に、いちばん直接こたえる形

### 案3：案1 ＋ 解いている最中にも☆を付けられる
- 出題カードの右上にも ☆（「これは明日もやらせたい」をその場で）
- ⚠️ お子さんが自分で付け外しできてしまう。**親が決める**という依頼からは外れるので、私は推しません

**私の推しは 案2**（① 親が外すまで残る と組み合わせ）です。★を付ける場所は一覧だけ、使う場所はホームの1ボタン、で迷いが少ないと思います。
